Hello from the logit demo

This page is served by a real Django app behind haproxy and nginx -- every request through that chain gets a W3C traceparent minted at the edge, and all four tiers (haproxy, nginx, this app, and logit itself) now agree on the same trace id: this app's own request span is a real OpenTelemetry span, exported over OTLP straight into logit's otlp_in, alongside its structured access log over syslog.

See it in Grafana

  1. Open {{ grafana_url }} -- anonymous access is on, no login.
  2. Dashboards → the logit folder → logit internals.
  3. Give it ten seconds: aggregate flushes on a 10s window.
